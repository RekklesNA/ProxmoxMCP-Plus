# ProxmoxMCP-Plus v0.7.3

Updates the pinned security automation used to review contributions:

- Updates both CodeQL Action steps to the same reviewed immutable revision,
  including the default CodeQL CLI 2.27.5 and upstream dependency updates.
  [PR #218](https://github.com/RekklesNA/ProxmoxMCP-Plus/pull/218)
- Updates Dependency Review Action from 5.0.0 to 5.0.1, including upstream
  error handling and dependency updates.
  [PR #219](https://github.com/RekklesNA/ProxmoxMCP-Plus/pull/219)

Action inputs, Node execution requirements, workflow permissions and enforced
security thresholds remain compatible. Application behavior and the hashed
runtime dependencies are unchanged.

Install `proxmox-mcp-plus==0.7.3` or pull
`ghcr.io/rekklesna/proxmoxmcp-plus:0.7.3`. Existing configuration and job
databases require no migration.
