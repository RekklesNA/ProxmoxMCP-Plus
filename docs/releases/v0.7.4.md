# ProxmoxMCP-Plus v0.7.4

`execute_vm_command` can now use SSH for a configured Linux VM. Add a profile
for the VM and pass `transport: "ssh"` to use it when Guest Agent command
execution is unavailable. The Guest Agent remains the default.

Each profile sets the guest address, user, private key and trusted host key.
Paramiko and system OpenSSH are supported. The existing command permissions
and approval checks apply. A call uses one transport, so a lost response
cannot trigger an automatic repeat through the other.

See the [VM SSH setup guide](../vm-ssh.md) and the original
[Discussion #217](https://github.com/RekklesNA/ProxmoxMCP-Plus/discussions/217).

Install `proxmox-mcp-plus==0.7.4` or pull
`ghcr.io/rekklesna/proxmoxmcp-plus:0.7.4`.
