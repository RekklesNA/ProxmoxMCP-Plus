# ProxmoxMCP-Plus v0.6.11

- Require OpenTelemetry API 1.45.2 or later in Python installations and pin
  1.45.2 with hashes in the container runtime lock. This addresses
  [GHSA-mf5v-w3w3-f6cg](https://github.com/advisories/GHSA-mf5v-w3w3-f6cg).
- Save Proxmox task status when the task log cannot be read. The last observed
  progress remains available, and the job audit records `polled_without_log`.
- Integrate [#208](https://github.com/RekklesNA/ProxmoxMCP-Plus/pull/208) to
  advertise idempotency for read-only tools and Code Mode lookups. Target
  discovery advertises network access and retries after malformed inventory
  without caching it.
- Measure OpenAPI rate-limit windows with elapsed time so wall-clock corrections
  do not freeze or clear a client's request allowance.
- Copy only packaging sources, runtime dependencies and example configurations
  into Docker images. CI verifies that an unrelated build-context file stays out
  of the image and that the runtime user cannot write directly to the source directory.

Upgrade to `proxmox-mcp-plus==0.6.11` or pull
`ghcr.io/rekklesna/proxmoxmcp-plus:0.6.11`. Recreate containers, restart
workers and reconnect MCP clients to refresh tool metadata. Existing job
databases and configuration can be reused without a migration.
