# ProxmoxMCP-Plus v0.6.10

## Changes

- Update the pinned GHCR login action from 4.7.0 to 4.8.0 (#200).
- Update CodeQL init and analyze together to the same pinned revision (#201, #202), resolving their version mismatch.
- Group future CodeQL action updates in Dependabot to keep both steps aligned (#203).

## Upgrade

Install `proxmox-mcp-plus==0.6.10` or pull `ghcr.io/rekklesna/proxmoxmcp-plus:0.6.10`. Restart workers or recreate containers and reconnect MCP clients. No configuration or database migration is required. Preserve existing configuration, credentials and job volumes.

To roll back, reinstall 0.6.9 or use its container image. Rolling back cannot reverse Proxmox operations already performed.

## Validation

The release gates cover Python 3.11 and 3.12, CodeQL, dependency and secret scanning, Windows contracts, container health and authentication, and package metadata. No live Proxmox operations are required by CI.
