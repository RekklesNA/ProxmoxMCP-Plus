# ProxmoxMCP-Plus v0.6.2

## Changes

- Update `pydantic-monty` from 0.0.22 to 1.1.0, including its client and runtime in the hashed universal dependency lock.
- Adapt Code Mode to Monty 1.1.0's feed and turn duration limits. Retain the 30-second wall-clock deadline, memory, recursion, suspension, tool-call and output limits, and a fresh sandbox session per request.
- Update immutable SHA pins for GitHub artifact upload/download and Docker QEMU, Buildx and build/push Actions.
- Keep release workflow tests checking immutable pins, the supported major version and both container architectures while allowing compatible Docker Action minor and patch updates.

## Validation

Local Windows/Python 3.13 validation passed 894 tests with 39 optional-environment skips. The Code Mode and provisioning regression suite passed 64 tests. Ruff, Mypy, the locked runtime dependency audit, package build and Twine checks passed. GitHub CI also checks Python 3.11/3.12 with PostgreSQL, Windows contracts, strict coverage, dependency security, secret scanning and CodeQL before publication.

## Upgrade

Upgrade to `proxmox-mcp-plus==0.6.2` or the matching container tag and restart workers. Preserve existing SQLite state and legacy OAuth metadata. No application configuration or database migration is required.
