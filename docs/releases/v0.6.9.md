# ProxmoxMCP-Plus v0.6.9

## Changes

- Upgrade pydantic-monty, pydantic-monty-client and pydantic-monty-runtime
  from 1.2.0 to 1.4.0 for Code Mode (#196). Regenerate the universal runtime
  lock and package hashes so source installs and container images use the
  same dependency versions.
- Allow mypy 2.x in development dependencies (#197).
- Update the SHA-pinned docker/login-action to 4.7.0 for GHCR publishing (#198).

## Upgrade

Install `proxmox-mcp-plus==0.6.9` or pull
`ghcr.io/rekklesna/proxmoxmcp-plus:0.6.9`. Restart workers or recreate containers
and reconnect MCP clients after upgrading. No database migration or new
configuration is required. Preserve existing credentials, configuration and job
volumes. To roll back, reinstall 0.6.8 or use its container image; this does not
reverse Proxmox operations already performed.

## Validation

Release gates cover Python 3.11/3.12 tests and coverage, Code Mode behavior,
Windows contracts, container health and authentication, static analysis,
dependency audits and package metadata consistency. Validation uses mocked
Proxmox APIs; no live guest operations are performed.
